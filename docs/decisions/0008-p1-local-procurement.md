No Render, sponsor SDK or additional dependency is required. Providers receive immutable source and bounded model access, never database handles or payment authority.

Mutable projections are updated only inside application transactions. Verification-to-charge linkage is guarded in SQL. Financial history and immutable quote/source/version rows reject update/delete.

Use one invocation row as its durable execution job instead of duplicating identical scheduling state in a separate jobs table. Direct status changes under BEGIN IMMEDIATE and unique constraints provide serialized transitions; lease tokens fence stale workers. Model requests are durably counted per task, including retries. Original absolute deadlines and the one coordinator repair survive restart.

Evidence links identify that snapshot and exact source path/lines. The model independently reviews the same source for architecture and risk; risk never receives architecture conclusions. Deterministic schema/evidence verification gates all charges, but is explicitly not proof of semantic truth. Final findings must cite accepted deliveries.
